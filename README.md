# NovaOS Alpha 0.1
Experimental Debian-based KDE Plasma live ISO for legacy BIOS and UEFI testing.

## Build on GitHub
1. Upload the contents of this ZIP to a new repository, preserving folders including `.github/workflows`.
2. Open **Actions** > **Build NovaOS ISO** > **Run workflow**.
3. When the build completes, download the artifact from the workflow run. Unzip it to get the ISO.

This is an early prototype, not a production-ready OS. It is a live image only; it has no installer. Do not repartition or install it over Windows. Test booting from USB first. Build success and compatibility are not guaranteed.
